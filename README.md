# Simple problem set

1. **拡張FizzBuzz**  
   - 1～50まで出力。3の倍数は“Fizz”、5の倍数は“Buzz”、両方の倍数は“FizzBuzz”。  
   - それ以外に、7の倍数は“Pop”と出力。  

2. **回文チェッカー**  
   - 入力文字列が回文かどうか判定。大文字小文字・空白・句読点を無視。  
   - コマンドライン／関数インターフェースで実装し、数例テスト。

3. **簡易JSONフォーマッター**  
   - 単一行のJSON文字列を「見やすく」インデント付きで整形出力。  
   - エラー時は「構文エラー: ○文字目付近」と表示。

4. **素数ジェネレーター**  
   - 引数 N を受け取り、N 以下の素数をリストアップ。  
   - エラトステネスの篩を使う or 単純チェックの両方で実装し、速度を比較。

5. **Anagram（アナグラム）判定**  
   - 2つの単語がアナグラムか判定。  
   - Unicode対応で日本語ワードにも対応（オプション）。

6. **簡単CLI電卓**  
   - `calc "3+4*2/ (1-5)^2"` のような式をパースして計算。  
   - 四則演算＋べき乗に対応し、優先順位を守る。

7. **単語出現頻度カウンター**  
   - テキストファイルを読み込み、単語ごとの出現回数を集計。  
   - 上位5語をソートして出力（大文字小文字区別オプション付き）。

8. **HTTPステータスチェッカー**  
   - 引数に渡したURL一覧を順番に `HEAD` リクエストしてステータスコードを表示。  
   - 並列／直列処理のどちらも試し、実装を比較。

9. **メールアドレス検証関数**  
   - 正規表現で「簡易的に」メールアドレス形式をチェック。  
   - ユニットテストで合格・不合格パターンを複数登録。

10. **ミニToDoリスト（メモリ版）**  
    - 以下の操作を関数で実装：追加・一覧取得・完了マーク・全削除。  
    - データはインメモリリストで OK。CLIやREPLで動かして試す。
